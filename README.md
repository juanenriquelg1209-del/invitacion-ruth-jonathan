# Invitación Ruth & Jhonatan — versión final

Proyecto Next.js listo para publicar en Vercel.

## Arrancar en local

```bash
npm install
npm run dev
```

Después abre http://localhost:3000

## Publicar en Vercel

1. Crea/importa un repositorio de GitHub con esta carpeta.
2. En Vercel selecciona **Add New → Project**.
3. Importa el repositorio.
4. Framework: Next.js.
5. Build/Install defaults.
6. Deploy.

No requiere dominio comprado: Vercel asignará una URL `*.vercel.app`.
